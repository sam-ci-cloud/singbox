# Accounting core corresponding source

Exact upstream tag v1.14.4 (commit `c005f35300ce76427dc285481ec5695f5b179cd2`, Go module sum in BUILD_PROVENANCE.json), plus the SBOX accounting and authenticated QUIC readiness patch. Source: https://github.com/SagerNet/sing-box/tree/v1.14.4 . The patch adds authenticated read-only StatsService RPC and shared managed-account TCP/UDP payload reservations; for 1.14.3+ it stops the quota guard inside the lifecycle scope cleanup that replaced `Server.Close`. Source filenames and all original licensing notices are retained. This derivative is supplied as the SBOX accounting core; no upstream endorsement is claimed.

Run `bash build.sh` on Linux AMD64 with tar, gzip, sha256sum and a compiler-compatible Linux kernel. The repaired build downloads the SHA-256-pinned official Go 1.27.4 toolchain and go.sum-verified modules from the official Go proxy. REQUIRED_MODULE_ZIPS.json is the historical module list. The full pinned dependency graph is in go.mod/go.sum. It runs the native Go regressions and checks the exact output SHA. No VPS, installation or system service is needed for this build. Additional disk space is needed for the uncompressed module cache and build cache.

`sing-box/` is the patched source, with the security dependency changes recorded in security-dependencies.patch and upstream default tag file. `sbox-accounting.patch` is the diff against the tagged commit, including the new files. `BUILD_PROVENANCE.json` records the original build command; its absolute paths are historical. `build.sh` uses relative paths and fixed flags. The stock-source and StatsService-only comparison builds use the same compiler and defaults, omitting the additional tags/patch as described in the original release testing.

Licenses: upstream GPL-3.0-or-later and its existing notice in LICENSE.sing-box; Go's license is inside the verified archive; individual Go modules include their own licenses inside their ZIPs. This preserves upstream dependencies, including upstream sum-verified Cronet/naive assets shipped by the official module. These assets are not newly authored C++ source builds; their provenance follows the pinned upstream modules. The claim of source compilation applies to the Go core and this patch. No independently downloaded third-party panel or opaque replacement core is used.

Read-only RPC uses a root-owned local secret. Never make the StatsService Internet-facing. Quota policy accepts only manager-generated user tags and cannot block the protected legacy identity. A mutex per managed account protects concurrent accepted and pending payload across stream and datagram operations. The policy watcher reloads every 100 ms and closes exhausted flow handles. The collector records measured bytes separately from unconfirmed allowances after a core restart. See the application source in ../src/.

The current SHA-256 is recorded in BUILD_PROVENANCE.json and the release manifest. After a corresponding-source update, run `python3 tools/core_inventory.py` to regenerate MANIFEST.json, SBOM.json, REQUIRED_MODULE_ZIPS.json and the third-party notices. See release pins in ../assets/release.json and the build script. Upstream names such as common/interrupt/ are functioning connection-lifecycle source, retained with the pinned upstream layout.

The complete resolved module graph and actual linked binary dependencies are in SBOM.json. All 140 linked Go modules have collected license notices; unlinked graph/test modules without a cached license are explicitly identified.

The 1.11.2 patch updates the native quota guard and provides a bounded in-memory HTTP readiness response for authenticated Hysteria2 and TUIC paths. Both features have native regression tests. The customized upstream tag, Go 1.27.4 and pinned module graph carry forward the security fixes recorded in the build manifest and security dependency patch.
